# ToolsDaily

Free everyday tools that run entirely in your browser — no uploads, no sign-up. Your files and text never leave your device.

## Tools

- **QR Code Generator** — turn any text or link into a QR code (SVG + PNG download)
- **Image Compressor** — shrink JPG/PNG/WebP images with a quality slider
- **Image Converter** — convert images between PNG, JPEG and WebP
- **Word Counter** — words, characters, sentences and reading time
- **Password Generator** — strong random passwords (crypto-secure)
- **Age Calculator** — exact age in years, months, days + next birthday countdown
- **Unit Converter** — length, weight and temperature
- **Color Converter** — HEX ↔ RGB ↔ HSL ↔ HSV
- **Text Case Converter** — UPPER, lower, Title, Sentence, alternating, reverse
- **JSON Formatter** — format, minify and validate JSON

## Tech

Plain static HTML/CSS/vanilla JS — no build step, no framework, no external requests (the QR library is vendored locally). Deploy the folder as-is on any static host.
