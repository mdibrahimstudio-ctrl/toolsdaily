Unlock PDF

Remove the password from a PDF you already know the password for — get back the same file, opening without a password. Everything runs in your browser; your file never leaves your device.

Drop a password-protected PDF here, or

Download unlocked PDF

This tool does not guess or crack passwords — it only removes protection when you already know the password. If you forgot the password, there is no way to open the file with this tool.

Privacy first: your PDF and password never leave your device — everything runs in your browser.

How to use

  1. Click the box (or drop a file onto it) and choose one password-protected PDF.
  2. Type the password you already know for that PDF.
  3. Click “Unlock PDF”, then download the same file without its password.

FAQ

Can this tool unlock a PDF if I forgot the password?

No. This tool does not guess or crack passwords — it only removes protection when you already know the password. If you forgot the password, there is no way to open the file with this tool.

What if my PDF is not password-protected?

The tool tells you so — “This PDF is not password-protected — nothing to unlock” — and does not produce a file. A PDF that already opens without a password has nothing to remove.

Are my PDF files uploaded to a server?

No. Unlocking happens entirely in your browser — your files never leave your device, and the password is never sent anywhere.
