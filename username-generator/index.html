How to use

  1. Type a keyword if you want your own word in the names, pick a style, and choose how many names to make.
  2. Click “Generate usernames” for a fresh list — every name in the list is unique.
  3. Copy a single name, copy them all at once, or download the whole list as a .txt file.

FAQ

How are the usernames made?

Each name is built from word lists — an adjective plus a noun, sometimes with a number or a separator — and every name in a batch is checked to be unique, so you never see the same idea twice.

Can I use my own word in the names?

Type a keyword and it is woven into the names as a prefix, suffix or middle part, so the ideas stay personal to you.

Are the names guaranteed to be free on Instagram or TikTok?

No — the generator cannot check whether a name is taken on any platform. Always search the name on the platform itself before you claim it.

Is my keyword saved anywhere?

No. Your keyword and the generated names stay in your browser and are never uploaded or saved anywhere.
