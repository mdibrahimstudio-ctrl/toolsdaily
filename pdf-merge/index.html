PDF Merge

Combine several PDFs into one file — contracts, chapters, scans — in the order you choose them.

📂 Drop PDF files here, or

    Download merged PDF

    How to use

    1. Click the box (or drop files onto it) and choose two or more PDF files.
    2. Check the list — files merge in the order shown.
    3. Click “Merge PDFs”, then download your combined document.

    FAQ

    Are my PDF files uploaded to a server?

    No. Merging happens entirely in your browser — your documents never leave your device.

    In what order are the files merged?

    Files are merged in the order shown in the list, which is the order you selected them. To change the order, clear the list and select the files again in the order you want.

    Why could a file not be added?

    Only PDF files can be merged. Password-protected (encrypted) or damaged PDFs cannot be read by the merger — remove the password or repair the file and try again.
