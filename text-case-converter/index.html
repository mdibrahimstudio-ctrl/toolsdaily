FAQ

What is Title Case?

Title Case capitalises the first letter of every word, like a headline: “The Quick Brown Fox”.

What is Sentence case?

Sentence case capitalises only the first letter of each sentence and lowercases everything else — handy for fixing text typed in all caps.

Can I undo a change?

There is no undo button, so keep a copy of important text before transforming it.
