How to use

  1. Type text and choose "Text → Morse" to encode it — letters become dots and dashes, words are separated by a slash ( / ) or three spaces.
  2. Choose "Morse → Text" and paste Morse code to decode it back — for example ... --- ... becomes SOS.
  3. Press "Play Morse audio" to hear the code as beeps, and use the speed slider to change the pace. Copy the result or download it as a .txt file.

FAQ

What is Morse code?

Morse code represents every letter and number as a pattern of short dots (.) and long dashes (-). For example, S is three dots (...), O is three dashes (---), and the famous distress call SOS is ... --- .... It was invented in the 1830s for the telegraph and is still used by radio amateurs today.

How do I decode Morse code back to text?

Choose "Morse → Text", then paste Morse code with a space between letters and a slash ( / ) or three spaces between words — for example ... --- ... decodes to SOS. Any pattern that is not a real Morse letter is shown as a question mark (?).

Is my text sent anywhere?

No. Translating to and from Morse code — and the audio playback — happens entirely in your browser. Your text is never uploaded or saved anywhere.
