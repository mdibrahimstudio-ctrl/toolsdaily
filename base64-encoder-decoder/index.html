How to use

  1. For text: type or paste it, then press Encode or Decode.

  3. To get a file back: paste its Base64, type a filename, and press Decode and prepare download.

FAQ

What is Base64?

Base64 turns binary data into plain text using 64 safe characters (letters, digits, + and /), so it can travel in places that only accept text, like JSON or URLs. It is an encoding, not encryption: anyone can decode it.

Can I encode a file, not just text?

Yes. Pick any file and the tool reads it in your browser and shows its Base64 text, which you can copy or download as a .txt file. You can also paste Base64 back and download the original file.

Is anything I upload stored?

No. Encoding and decoding happen entirely in your browser — your text and files are never uploaded or saved anywhere.
