How to use

  1. Drop a scanned or image-only PDF onto the box (or click it to choose one). One file at a time.
  2. Click “Start OCR”. The first run downloads the OCR engine (about 6 MB) — your browser caches it, so later runs start right away. Each page is rendered and read in turn.
  3. Read the extracted text page by page below, then download it as a .txt file. This version reads English only, and accuracy depends on scan quality.

FAQ

Is my PDF uploaded to a server?

No. The OCR runs entirely in your browser — your PDF never leaves your device, and nothing is uploaded or saved anywhere.

Why does the first run take a moment?

The first run downloads the OCR engine (about 6 MB: the recognition core and the English language model) and your browser caches it, so later runs start right away. This version reads English only, and accuracy depends on scan quality — clean, straight, high-contrast scans read best.

Can I get a searchable PDF back?

Not in this version. OCR PDF downloads the extracted text as a plain .txt file, one section per page. A searchable-PDF output is not included in v1.
