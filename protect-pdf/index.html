Protect PDF

Lock a PDF with a password — AES-256 encryption, so only people with the password can open it.

Drop a PDF file here, or

Download protected PDF

Keep your password safe: the password cannot be recovered if lost — there is no back door. An already-encrypted PDF cannot be re-encrypted directly — unlock it first with Unlock PDF. The protected file needs a viewer that supports AES-256 (all current browsers and PDF readers do).

Privacy first: your PDF and password never leave your device — everything runs in your browser.

How to use

  1. Click the box (or drop a file onto it) and choose one PDF file.
  2. Type a password (at least 4 characters) and confirm it.
  3. Click “Protect PDF”, then download your password-protected file.

FAQ

What happens if I forget the password?

The password cannot be recovered if lost — it is never sent anywhere and there is no back door, so a forgotten password means the PDF cannot be opened again. Store it somewhere safe before you share the file.

Can I protect a PDF that already has a password?

No — an already-encrypted PDF cannot be re-encrypted directly. Unlock it first with Unlock PDF, then protect it with the new password.

Is my PDF uploaded to a server?

No. The AES-256 encryption runs entirely in your browser — your file never leaves your device, and the password is never sent anywhere.
