How to use

  1. Pick a start date and an end date, then press Calculate difference.
  2. Read the calendar breakdown (years, months, days) plus total days, weeks and complete months.
  3. To shift a date, enter it below with a number of days — a negative number subtracts days.

FAQ

Does the calculator handle leap years?

Yes. It counts real calendar days, so 29 February is included whenever it falls between your two dates.

Does the order of the dates matter?

No. The earlier date is used as the start either way, so swapping the two dates gives the same result.

What does Include end date do?

It adds one day to the total, counting both the start and end dates. With it off, the difference between the same date twice is 0 days; with it on, it is 1 day.
