JSON Formatter

Format, minify and validate JSON — with errors you can actually understand.

How to use

  1. Paste your JSON into the input box.
  2. Click Format to pretty-print it (choose 2 or 4 spaces), Minify to compress it, or Validate to check it.
  3. Copy the output, or download it as a .json file.

FAQ

Why is my JSON invalid?

Common causes are missing commas, trailing commas, single quotes instead of double quotes, or unquoted keys. The error message shows exactly what the parser found.

Does formatting change my data?

No. Format and Minify only change whitespace — the data itself stays identical.

Is my JSON uploaded for processing?

Never. Parsing happens locally in your browser, so it is safe for private data.
